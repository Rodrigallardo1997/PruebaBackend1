Plataforma de Gestión Académica

Sistema integral desarrollado con Django 6.1 y Django REST Framework (DRF). Implementa una arquitectura desacoplada donde las interfaces visuales enmascaran los endpoints REST consumiendo datos asíncronamente vía fetch(), autenticación moderna con tokens JWT, filtros en tiempo real y documentación OpenAPI / Swagger.

Módulos de Gestión Disponibles

Explora lo que ofrece cada módulo de la plataforma:

Docentes
Modelo: Teacher

Administración completa del cuerpo docente. Permite crear profesores, editar su información personal y visualizar asignaturas asociadas.

Requiere Login Entrar
Asignaturas
Modelo: Course

Catálogo académico de cursos con asignación dinámica de docentes mediante claves foráneas y regla CASCADE en base de datos.

Requiere Login Entrar
Estudiantes
Modelo: Student & StudentCourse

Registro de alumnos y gestión de matrículas en asignaturas mediante relación Muchos a Muchos con control de duplicados (unique_together).

Backend & Frontend Integrados
Enmascaramiento Fetch

Vistas HTML que consumen endpoints JSON de forma asíncrona mediante JavaScript sin recargar.

Tokens JWT (SimpleJWT)

Autenticación sin estado mediante pares de tokens (Access y Refresh) en /api/token/.

Filtros django-filter

Filtrado en endpoints REST por parámetros URL, búsqueda textual ?search= y ordenamiento.
